# Remotion Effects Library: progress-driven Remotion effects

> Source: https://github.com/holy-cursor/Remotion-Effects-Library. Copy the library files (not gallery/) into a Remotion 4 project and import from them. Agents: see SKILL.md.
> No license file yet: all rights reserved until one is added.

## How to use
- Every effect is a pure function of `progress` (0..1). Compute it from `useCurrentFrame()` with `interpolate(..., {extrapolateLeft: 'clamp', extrapolateRight: 'clamp'})`.
- Wrapper effects animate their `children`. Text effects take `text` and inherit font size. Scene effects fill their parent box; give the parent explicit width and height.
- Shared props: progress, speed, delay, theme, palette, accent, fontFamily, background, scale, grain, grid, tokens, style.
- Defaults are transparent (`background="none"`). Pass `background="canvas"` for a themed stage with optional `grid` and `grain`.
- Wrap a subtree in `<EffectTheme palette=… theme=… accent=…>` to set defaults for every effect below it.

## Palettes
- `saint-orange` Saint Orange: The original orange and cream look of this library, kept as-is.
- `graphite` Graphite: Neutral product UI: quiet greys with one cobalt accent.
- `editorial` Editorial: Printed-matter warmth: bone paper, black ink, a single vermilion.
- `indigo-signal` Indigo Signal: Indigo, black and white with a lime signal colour for one key moment.
- `monochrome` Monochrome: Grayscale only. Motion and type carry everything.
- `ember` Late Ember: Warm glow on near-black; a dark-first sibling of Saint Orange.

## Style presets
- `saint-orange` Saint Orange: Original cream and orange, crisp sans, no grain. Matches the old gallery. (palette saint-orange, light, font sans, grain 0, speed 1)
- `saint-night` Saint Night: Saint Orange on warm black with a little film grain. (palette saint-orange, dark, font sans, grain 0.35, speed 1)
- `studio-graphite` Studio Graphite: Product-launch neutral. Dark graphite, cobalt focus, brisk timing. (palette graphite, dark, font grotesk, grain 0.15, speed 1.25)
- `broadsheet` Broadsheet: Editorial serif on bone paper, unhurried, with a print-like tooth. (palette editorial, light, font serif, grain 0.45, speed 0.85)
- `signal` Signal: Indigo night with a lime moment. Mono labels, fast in, long hold. (palette indigo-signal, dark, font mono, grain 0.2, speed 1.5)
- `ink-only` Ink Only: Monochrome and calm. Good for checking that motion reads without colour. (palette monochrome, light, font sans, grain 0.1, speed 0.9)
- `late-ember` Late Ember: Glowing warm accents on near-black, heavier grain, slower settle. (palette ember, dark, font display, grain 0.55, speed 0.8)

## Shared props
| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `progress` (required) | `number` | 0 | Normalised timeline position. Drive it from useCurrentFrame(). |
| `speed` | `number` | 1 | Speed multiplier on the progress timeline. 2 finishes at the halfway mark. |
| `delay` | `number` | 0 | Share of the timeline before motion starts. |
| `theme` | `"light" \| "dark" \| Partial<LegacyPalette>` | "light" | Light or dark role set. Legacy palette objects are also accepted. |
| `palette` | `PaletteId` | "saint-orange" | Palette id from core/tokens. |
| `accent` | `string` | — | Overrides the palette accent role. |
| `fontFamily` | `FontId \| string` | "inherit" | Font id (sans, serif, mono…) or any CSS font-family. Default inherits. |
| `background` | `"none" \| "canvas" \| "surface" \| string` | "none" | Backdrop. "none" keeps the transparent legacy behaviour; any CSS colour also works. |
| `scale` | `number` | 1 | Uniform content scale. |
| `grain` | `number` | 0 | Film grain over the backdrop (needs a background). |
| `grid` | `boolean` | false | Dotted grid on the backdrop (needs a background). |
| `tokens` | `Partial<Roles>` | — | Fine-grained colour role overrides. |
| `style` | `React.CSSProperties` | — | Inline styles on the effect root. |

Give any SVG silhouette (text, paths) solid depth. Pass `contours` for lit, rotating walls instead.

- Category: Primitives. Kind: primitive. Source: `shared-effects/Extrude.tsx`.

- Not progress-driven: animate dx/dy yourself.
